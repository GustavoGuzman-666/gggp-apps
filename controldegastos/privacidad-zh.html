隐私政策

应用：Control de Gastos（Android 和 Windows）· 最后更新：2026 年 11 月 13 日

本隐私政策说明 Control de Gastos 的 Android 和 Windows 应用（“本应用”“我们”）会处理哪些信息、如何使用、存放在哪里、与谁共享，以及你如何删除这些信息。Control de Gastos 是一款个人理财工具，帮助你记录分期购买、每月固定支出以及每个人应付的金额。本应用由一名个人开发者开发和维护，联系邮箱：gggp.controldegastos@gmail.com。

1. 概要

  • 你输入的数据保存在你的设备上。我们没有服务器，也不会收到你的数据。
  • 如果你选择连接云账号，本应用会把备份文件保存到你自己的云存储中，方便你在其他设备上恢复或同步数据：Microsoft OneDrive（Android 和 Windows）或 Google Drive（Android）。
  • 我们不会出售、出租或与任何人共享你的数据，不显示广告，也不使用任何统计分析或跟踪工具。

2. 本应用处理的信息

数据来源存放位置
财务记录：分期购买（商品、金额、首次扣款日期、分期数、银行卡或商店、持卡人）、固定支出（项目、金额、人员、商户）、外币消费及汇率、工资和应用设置 由你在应用中输入 在你的设备上，存放于应用的私有存储中。如果你连接 OneDrive 或 Google Drive，还会保存在你自己云账号的备份文件中。
人员、银行卡/商店和商户的名称（“列表”） 由你在应用中输入 同上
已连接的 Microsoft 或 Google 账号的电子邮箱（仅在你连接账号时） 你授权访问时由 Microsoft 或 Google 提供 仅保存在你的设备上，用于显示当前连接的账号
Microsoft 登录令牌（仅在你连接 OneDrive 时） 你登录时由 Microsoft 提供 仅保存在你的设备上，存放于应用的私有存储中（在 Windows 上会针对你的 Windows 用户加密），这样你无需每次都登录。断开连接时会被删除。
Google 访问令牌（仅在你连接 Google Drive 时） 你授权访问时由 Google 提供 有效期很短；需要时向 Google Play 服务申请。本应用不保存 Google 密码，也不保存长期有效的 Google 令牌。

本应用不会收集你的姓名、电话号码、联系人、照片、位置、设备标识符、广告 ID、浏览记录或使用统计，也不会读取你的短信或通知。

3. Microsoft 账号与 OneDrive 访问

连接 OneDrive 是可选的。如果你在设置 → 同步中点击“使用 Microsoft 登录”，本应用会通过 Microsoft 身份平台请求以下权限：

  • Files.ReadWrite.AppFolder —— 读取和写入你 OneDrive 中本应用专属文件夹（应用文件夹）里的文件。本应用无法查看、列出、读取或修改你的任何其他文件或文件夹。
  • User.Read —— 读取你的基本资料（电子邮箱），用于显示当前连接的账号。
  • offline_access —— 保持登录状态，无需每次输入密码。

本应用如何使用这些权限：在你 OneDrive 的专属文件夹中创建备份文件（每个备份一个 JSON 文件，名称由你决定），内容为第 2 节所述数据；并读取和更新你选定的备份，以保持各设备同步并让你恢复数据。同步只是把你的数据与所选备份合并；替换或删除备份需要你明确地二次确认。

对从 Microsoft 获得的信息的使用：通过 Microsoft Graph 获得的信息仅用于提供应用中可见的备份与同步功能。除非为提供该功能或遵守法律所必需，否则不会转让给第三方；不会用于广告；除非经你明确同意、出于安全目的或为遵守适用法律，否则不会被人工查看。

4. Google 账号与 Google Drive 访问（Android）

连接 Google Drive 是可选的，仅在 Android 应用中提供。如果你在设置 → 同步中点击“使用 Google 登录”，本应用会通过 Google 登录（Google Play 服务）请求一项权限：

  • https://www.googleapis.com/auth/drive.appdata —— 读取和写入你 Google Drive 中本应用专属的隐藏数据文件夹里的文件。本应用无法查看、列出、读取或修改你 Drive 中的任何其他文件或文件夹。应用中显示的电子邮箱也是通过这项权限获得的。

本应用如何使用该权限：在该隐藏文件夹中创建备份文件（每个备份一个 JSON 文件，名称由你决定），内容为第 2 节所述数据；并读取和更新你选定的备份，以保持各设备同步并让你恢复数据。同步只是把你的数据与所选备份合并；替换或删除备份需要你明确地二次确认。该隐藏文件夹不会出现在 Google Drive 的常规文件列表中。

Google API 服务用户数据政策：Control de Gastos 对从 Google API 获得的信息的使用，以及将其转让给任何其他应用，都将遵守 Google API 服务用户数据政策，包括“限制性使用”要求。具体而言，从 Google 获得的信息仅用于提供应用中可见的备份与同步功能；除非为提供该功能、出于安全目的或为遵守法律所必需，否则不会转让给第三方；不会用于广告，包括再营销或基于兴趣的广告；不会用于开发、改进或训练通用机器学习模型；除非经你明确同意、出于安全目的或为遵守适用法律，否则不会被人工查看。

5. 我们如何使用这些信息

  • 计算并显示你的月度汇总、分期、固定支出、每人金额和结余。
  • 在两次使用之间把你的数据保存在设备上。
  • 如果你连接 OneDrive 或 Google Drive：备份你的数据，并在你的设备之间同步，合并在不同设备上所做的更改。

我们不会将你的信息用于任何其他目的，例如广告、用户画像、信贷决策或训练机器学习模型。

6. 共享与披露

我们不会向第三方共享、出售、出租或披露你的信息。本应用只进行三类网络通信，且始终使用 HTTPS：（1）与 Microsoft（登录以及 Microsoft Graph / OneDrive 服务），仅在你已连接 Microsoft 账号时；（2）与 Google（Google 登录和 Google Drive API），仅在你已连接 Google 账号时；（3）与免费汇率服务 open.er-api.com，仅在你点击“外币”标签页中的“从互联网更新”时。最后一项请求只获取美元、欧元和英镑的汇率：不会发送你的数据、姓名或标识符，不过与任何互联网连接一样，该服务可以看到访问它所用的 IP 地址。你在 OneDrive 或 Google Drive 中的数据受 Microsoft 或 Google 自己的隐私声明和安全措施约束。只有在法律要求时，我们才可能披露信息。

7. 存储、安全与保留

  • 在你的设备上：数据保存在应用的私有存储中，操作系统会将其与其他应用隔离。请为设备设置屏幕锁。
  • 在 OneDrive 或 Google Drive 中：备份文件位于你自己的账号中，受你的 Microsoft 或 Google 账号安全保护。
  • 保留：你的数据会一直保留，直到你将其删除。开发者不保留任何副本，因为数据从未到达开发者。

8. 你的选择以及如何删除数据

  • 编辑或删除记录：你可以在应用内编辑或删除任何购买、支出、人员、银行卡或商户。
  • 停止同步：在应用中进入设置 → 同步 → 断开连接。这会从设备上移除登录信息。
  • 删除云端数据：在应用中通过设置 → 备份 → 删除备份删除备份。你也可以在 OneDrive 中从本应用的文件夹删除，或在 Google Drive 的设置 → 管理应用 → Control de Gastos → 删除隐藏的应用数据中删除。
  • 撤销访问权限：Microsoft：account.live.com/consent/Manage（个人账号）或 myapps.microsoft.com（工作或学校账号）；Google：myaccount.google.com/permissions。
  • 删除本地数据：卸载应用，或在系统设置中清除其存储。

由于开发者并不持有你的数据，按上述步骤删除即可将其彻底清除。如对你的数据有任何请求，也可以写信至 gggp.controldegastos@gmail.com。

9. 儿童

本应用不面向 13 岁以下儿童，也不会有意收集他们的个人信息。

10. 本政策的变更

如果本政策发生变更，新版本将发布在此地址并更新日期。如果变更影响从 Microsoft 或 Google 获得的信息的使用方式，在未再次征得你同意的情况下，本应用不会将变更应用于你已提供的数据。
